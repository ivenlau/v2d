# V2D

浏览器视频嗅探与转存扩展。嗅探页面中正在播放的视频，一键下载到本地，或转存到 115 网盘。

## 功能

- **自动嗅探**：后台监听网络请求，支持直链（mp4/mkv 等）与 HLS（m3u8）分段流；打开弹窗自动扫描页面媒体元素
- **下载到本地**：直链一键下载；HLS 分段并发下载并转封装为 MP4（支持 AES-128 解密，H.265 自动降级合并 TS）
- **转存 115 网盘**：秒传优先（命中零上传），未命中走 OSS 分片直传；流式管线，大文件内存占用恒定
- **断点续传**：暂停 / 中断后从断点继续，SHA1 状态跨会话保留
- **手动离线**：在传输管理页粘贴直链 / 磁力 / ed2k，由 115 服务器代下载
- **传输管理**：队列与历史、暂停 / 继续 / 重试 / 删除、失败原因人话化

## 安装（从源码构建）

要求 Node.js ≥ 20 与 [pnpm](https://pnpm.io)。

```bash
pnpm install
pnpm build        # 产物在 .output/chrome-mv3/
```

Chrome 打开 `chrome://extensions` → 开启「开发者模式」→ 「加载已解压的扩展程序」→ 选择 `.output/chrome-mv3` 目录。

## 使用

1. 打开有视频的页面，工具栏图标显示角标
2. 点击图标：直链点「⬇ 存本地」；HLS 点「⬇ 存本地」自动合并为 MP4
3. 转存 115（可选）：设置页打开「115 转存」→ 扫码授权 → 候选卡片出现「☁ 转存115」
4. 「传输管理」页查看队列进度、暂停 / 重试、清理历史

## 开发

```bash
pnpm dev                # 开发模式（HMR）
pnpm test               # 单元测试
pnpm compile            # 类型检查
pnpm build              # 生产构建
node e2e/repro-transfer.mjs   # 端到端链路验证（需先 pnpm build）
```

## 目录结构

```
src/
├─ entrypoints/      # background / popup / options / manager / offscreen
├─ background/       # 传输队列与 115 离线通道
├─ core/             # 嗅探判定、m3u8 解析、设置等平台无关逻辑
├─ offscreen/        # 下载 / 合并 / 上传管线（OPFS 暂存 + remux）
├─ providers/115/    # 115 开放平台协议层（鉴权 / 秒传 / OSS 直传 / 离线）
└─ public/icons/     # 扩展图标
design/icons/        # 图标设计源文件与预览
e2e/                 # 端到端链路复现脚本
```

## 说明

- 仅处理无 DRM 保护的内容；下载受版权保护的内容可能违反目标网站服务条款，请自行承担合规责任
- 转存 115 需要 115 账号授权，离线下载为 115 会员功能
