# M5 站点适配清单

> 2026-09-24 梳理。适配层 = 通用嗅探之上的增强（清晰度枚举 / 正片过滤 / 命名 / 登录态复用 / 双轨合并）。
> 通用嗅探已能覆盖「明文直链 / 无鉴权 HLS」的站点——适配器解决的是拿不到、拿不全、拿不好那部分。

## 总原则

| 类别 | 策略 |
|---|---|
| DRM（Widevine/FairPlay/国内自研加密 VIP 正片） | ❌ 明确不支持，检测到即提示 |
| 直播流（斗鱼/虎牙/Twitch 直播间） | ❌ 不支持（仅点播/VOD） |
| 明文直链 / 无鉴权 HLS | ✅ 通用嗅探已覆盖，无需适配器 |
| 签名 URL / 双轨 DASH / 需登录态高清 | 🔧 需要站点适配器 |

## P0 — 首批（✅ 全部实现，2026-09-24）

| 站点 | 技术形态 | 难度 | 状态 |
|---|---|---|---|
| **B站 bilibili.com** | DASH 双轨（m4s 音视频分离）+ playurl API | ★★★ | ✅ 双轨 mediabunny remux + `__playinfo__` 探针（清晰度枚举/音轨配对/mcdn 过滤） |
| **抖音 douyin.com** | 签名 mp4 直链 | ★★ | ✅ `_ROUTER_DATA` 探针 → 无水印源画质直链（ratio=1080p） |
| **快手 kuaishou.com** | 签名 mp4 | ★★ | ✅ `__APOLLO_STATE__` 深度查找 mainMvUrls（容忍结构变化） |
| **小红书 xiaohongshu.com** | 签名 mp4 | ★ | ✅ `noteDetailMap` 探针取最高画质流 |
| **微博 weibo.com** | mp4 直链 | ★ | ✅ 通用嗅探已覆盖，无需专项适配器 |

> 签名直链类站点（抖音/快手/小红书）的 URL 有时效性：嗅探后请尽快转存/下载；过期后重新扫描即可。

| 站点 | 技术形态 | 难度 | 状态 |
|---|---|---|---|

## P1.5 — 海外成年向站点（18+，✅ 全部 best-effort 实现，2026-09-24）

> 多数为明文 mp4 / 无鉴权 HLS，通用嗅探已基本可用；适配器补质量枚举、命名与 Referer 规则。
> 仅对成年用户可用，站点自带年龄门槛，插件不做绕过。站点改版频繁，探针为 best-effort，
> 失败时通用嗅探兜底（多数站点的 m3u8/mp4 网络请求仍会被引擎 A 捕获）。
> 出于通用性考虑，下表使用代称；**具体域名以 `siteProbesOverseas.ts` 的 hostPattern 为准**。

| 代称 | 技术形态 | 难度 | 状态 |
|---|---|---|---|
| **P 站** | mediaDefinitions 多清晰度 m3u8 | ★★ | ✅ 内联脚本提取（含多码率变体） |
| **XV 站** | setVideoUrlHigh/Low 内联调用 | ★ | ✅ 高画质优先 |
| **仓鼠站** | window.initials__ 深度收集 m3u8/mp4 | ★★ | ✅ MAIN world 深度遍历 |
| **XN 站** | setVideoUrlHigh/Low（与 XV 站同系） | ★ | ✅ 复用探针 |
| **Y 站** | 内联脚本 m3u8/mp4 | ★ | ✅ 通用脚本抓取探针 |
| **SB 站** | 内联脚本 m3u8 + mp4 | ★ | ✅ 通用脚本抓取探针 |
| **E 站** | 内联脚本 mp4（含 4K） | ★ | ✅ 通用脚本抓取探针 |
| **RG 站** | 播放直出 mp4 | ★ | ✅ 通用嗅探已覆盖，无需适配器 |

## P2 — 视情况投入

| 站点 | 说明 |
|---|---|
| 腾讯视频 / 爱奇艺 / 优酷 / 芒果TV | 免费内容多为普通 HLS（通用嗅探可及 + 小适配）；**VIP 正片为 DRM/自研加密，明确不支持**。投入产出比低，建议只做「正片过滤 + 明确提示」，不做破解 |
| 西瓜视频 / 搜狐视频 / AcFun | HLS 为主，通用嗅探 + 小适配，视需求排期 |
| Facebook / VK / Niconico | 登录态 + 区域差异大，视需求 |
| Streamable / Imgur / 9gag 等 | 明文直链，通用嗅探基本已覆盖 |

## 特殊说明

| 站点 | 结论 |
|---|---|
| **YouTube** | ⚠️ 不承诺。SABR + PoToken 加固后扩展形态的第三方下载极不稳定（yt-dlp 都在反复攻防）。策略：仅通用嗅探尽力而为，不投入专项适配 |
| **Netflix / Disney+ / HBO Max / Prime Video** | ❌ Widevine DRM，不做 |
| **斗鱼 / 虎牙 / Twitch（直播）** | ❌ 直播不支持 |

## 建议排期

- **M5.1（国内）**：双轨 remux 基建 → B站 → 抖音 → 快手/小红书/微博（约 1~1.5 周）
- **M5.2（海外）**：X → Reddit（复用双轨）→ Vimeo → TikTok/Instagram/Dailymotion（约 1 周）
- **P1.5 成人站**：与 M5.2 并行插入——多为 ★~★★ 改动小，且大部分通用嗅探已可用，按实际需求勾选即可
