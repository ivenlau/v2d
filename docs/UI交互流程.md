# V2D UI 交互流程（M4 完成后现状）

> 对应代码：`src/entrypoints/{popup,options,manager,offscreen}` + SW 角标/嗅探。版本 2026-09-24。

## 0. 界面总览

```
┌─ 常驻（无界面）────────────────────────────────────────────┐
│ 引擎A webRequest 嗅探 ──► 候选登记 ──► 工具栏角标数字       │
└──────────────────────────┬─────────────────────────────────┘
                           ▼ 点击图标
┌─ Popup（主入口）───────────────────────────────────────────┐
│ 候选列表 · 一键存本地/转存115 · 清晰度展开 · 任务进度条     │
│   ├─「传输管理」──► Manager 全页（队列/历史/操作）         │
│   └─「⚙ 设置」/「开启115」──► Options 设置页               │
└────────────────────────────────────────────────────────────┘
```

## 1. Popup（主入口）

### 打开时自动发生
1. 头部显示当前站点域名
2. 注入一次 DOM 扫描（引擎 B）补充候选；引擎 A 的持续嗅探结果直接呈现
3. 懒探测前 3 个未探测项（直链探大小 / HLS 解析出清晰度与分段数）
4. 黑名单站点 → 顶部横幅「此站点已关闭嗅探 [在此站点启用]」
5. 115 未启用 → 底部引导条「💡 想一键转存到 115 网盘？开启 →」（唯一的 115 痕迹，产品红线）

### 头部
- `⟳` 重新扫描本页 ｜ `⚙` 打开设置

### 候选列表（按「正片>音轨、大文件优先」打分排序）

| 类型 | 徽章 | 操作 |
|---|---|---|
| 直链 mp4/mkv… | `直链` | **[⬇ 存本地]**（一键落 Downloads/V2D/）＋ [☁ 转存115]（启用后） |
| HLS m3u8 | `HLS` | **[⬇ 存本地]**（合并 MP4，自动最高码率）＋ [☁ 转存115] ＋ [清晰度/解析] |
| DASH | `DASH` | 「后续版本」注记（M5） |
| blob 内嵌流 | `内嵌流` | 置灰说明（M3+ 深捕获未实装） |

- HLS 点「清晰度」展开：逐档显示 分辨率/码率 + 每档 [⬇] [☁]
- 附加信息行：分段数 · 时长 · 直播流（按钮禁用+标注）· AES-128（自动解密）· 探测失败原因

### 底部
- 进行中任务（最多 3 条）：状态 + 进度条 + 百分比/速度/分段进度 + 人话化错误 + 迷你按钮
  - 直链下载中 → `⏸ 暂停`；暂停 → `▶ 继续`；失败/取消 → `↻ 重试`；均带 `×` 取消
- `传输管理` → 新标签打开管理页 ｜ `共 N 个候选`

## 2. 转存到 115 的完整旅程（首次）

```
popup 引导条「开启 →」
   ▼
Options：打开「115 转存」开关
   ├─ 弹出权限申请（*.115.com / *.aliyuncs.com，拒绝则开关回弹）
   ▼
认证引导（二选一）
   ├─ 扫码：生成二维码 → 115 App 扫码确认 → 自动变「已连接」
   └─ 导入 Token：粘贴 access/refresh（可来自 tg115bot）→ 自动验证
   ▼
已连接面板：空间用量 ｜ 默认保存目录（已保存路径常驻显示 + 面包屑浏览/新建/选定/恢复默认规则）
            转存通道说明（直传+秒传优先；离线彩蛋在 Manager）｜ 退出登录
   ▼
回到 popup：候选出现「☁ 转存115」→ 点击入队（关闭开关/设置变更时 popup 实时同步显隐）
```

- 关闭开关 = 一键回到纯本地模式（收回 host 权限；token 保留，「退出登录」才清）
- token 失效 → 面板自动降级为「待认证」并给重认证入口；本地下载永不受影响

## 3. 任务流转（转存/合并下载入队后）

```
点击「☁ 转存115」/ HLS「⬇ 存本地」
   ▼ 入队（串行队列，popup 底部与 Manager 实时进度）
自动通道（2026-09-24 起）：一律「浏览器直传」
   m3u8 ──► 合并管线：分段并发下载(+AES-128解密) → mux.js 转封装 MP4 → OPFS 暂存+SHA1
   直链   ──► OPFS 暂存 + 增量 SHA1（支持断点续传/暂停）
   ▼
秒传探测（UI 阶段「秒传检测中」）──命中──► 完成（零上传，标记「秒传命中」）
   │未命中
   ▼
OSS 分片直传 ──► 完成
```

🥚 **115 离线下载 = 手动彩蛋**（2026-09-24 移出自动通道）：Manager 页顶部「115 离线任务」输入框，
手动粘贴 直链/磁力/ed2k 提交，115 服务器代下载（会员功能），任务同样进队列展示进度。
失败不自动降级，错误信息会提示改用「☁ 转存115」直传。

出口：cloud → 115 网盘 `/来自浏览器/{站点}/{年-月}/`（或自选目录）；local（仅 HLS）→ 合并完经 blob URL 落 `Downloads/V2D/`

## 4. Manager 传输管理页

- 顶部「🥚 115 离线任务」输入框（仅 115 启用时显示）：粘贴直链/磁力/ed2k 提交
- 「进行中」区：状态徽章（排队/提交离线/115转存/下载/校验/**秒传检测中**/上传/保存/暂停）+ 文件名 + 目标 + 进度条 + 速度/字节/分段 + 人话化错误
- 「历史」区：已完成/失败/已取消 + 单条「删除」（连带清暂存）；顶部「清除已完成」
- 操作按钮随状态出现：`⏸ 暂停`（仅直链下载中）`▶ 继续` `↻ 重试`（保留断点）`取消` `删除`
- 刷新：任务事件实时 + 3s 兜底轮询

## 5. 断点与容错（用户可感知行为）

| 场景 | 表现 |
|---|---|
| 暂停/继续（直链） | 保留 OPFS 暂存 + SHA1 状态；继续从断点拉流，产物哈希仍正确 |
| 下载失败 | 暂存保留，`↻ 重试` 即断点续传；错误人话化（403 防盗链→建议先播放 / 404→刷新页面 / STS 超窗→建议离线通道） |
| 浏览器重启 | 非终态任务自动回队列断点续传；「保存本地」中断的任务明确提示需重试 |
| 直播流 / SAMPLE-AES | 按钮+管线双重拦截，说明原因 |
| H.265 等 HLS | 自动降级合并为 .ts（非 mp4） |

## 6. 任务状态机（UI 可见）

```
queued → downloading → hashing → uploading → done
              │⏸                    │
              ▼                     ├─(HLS local)→ saving → done
           paused ──▶──┘            │
  offline-adding → offline-polling ──(失败,auto)──► 回 queued 走直传
任意进行态 ──► cancelled / failed ──↻ retry──► queued
```
